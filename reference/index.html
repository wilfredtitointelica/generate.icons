Referencia de generate-fonts

Guías del generador de fuentes de iconos: de Figma (o de una carpeta de SVG) a dist/, y de dist/ al proyecto. El detalle de todos los comandos está en generate-fonts/README.md.

1. Generar fuente Desde Figma o desde SVG copiados en source/, con /generar-fuente o con comandos. 2. Conectar con Figma (token) Solo para fuentes de Figma: crear el token, guardarlo en .env y probar la conexión. 3. Exportar fuente Copiar una fuente generada a la carpeta de un proyecto y usarla en Angular.

Flujo completo

Figma ── npm run pull (token)          SVG compartidos ── copiar a mano
                     │                                   │
                     └──────────────┬────────────────────┘
                                    ▼
                        fonts/<fuente>/source/
                                    │  npm run build
                                    ▼
                  fonts/<fuente>/dist/ + icons.json
                                    │  npm run export (copia)
                                    ▼
                                 proyecto
  1. Generar la fuente: de Figma (con token, npm run pull) o copiando los SVG en source/, y npm run build -- <fuente>.
  2. Revisar la vista previa fonts/<fuente>/dist/<fuente>.html.
  3. Exportar la fuente al proyecto.

Con Claude Code: /generar-fuente (pasos 1 y 2) y /exportar-fuente (paso 3).

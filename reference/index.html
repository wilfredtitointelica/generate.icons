Guías del generador de fuentes de iconos: de Figma (o de una carpeta de SVG) a dist/, y de dist/ al proyecto. El detalle de todos los comandos está en generate.icons/README.md.

Después de clonar el repositorio

Se hace una sola vez por equipo, desde generate.icons/. El token solo hace falta para fuentes que vienen de Figma.

  1. Node.js 22 o superior node -v
  2. Instalar dependencias Instala las versiones fijadas y aplica el parche de fantasticon. npm ci
  3. Token de Figma en .env Copia la plantilla y pega tu token personal (File content: Read-only). .env no se sube. cp .env.example .env
  4. Probar la conexión Simulación: solo lee de Figma, no escribe nada. npm run pull -- incontrol-icons --dry-run

Guías

1 Configurar y conectar con Figma Crear el token, guardarlo en .env, probar la conexión y renovarlo cuando caduque. 2 Generar fuente Desde Figma o desde SVG copiados en source/, con /generar-fuente o con comandos. 3 Exportar fuente Copiar una fuente generada a la carpeta de un proyecto y usarla en Angular.

Destino proyecto
  1. Configurar el entorno y el token de Figma (una vez).
  2. Generar la fuente: de Figma (npm run pull) o copiando los SVG en source/, y npm run build -- <fuente>.
  3. Revisar la vista previa fonts/<fuente>/dist/<fuente>.html.
  4. Exportar la fuente al proyecto.
Con Claude Code: /generar-fuente (pasos 2 y 3) y /exportar-fuente (paso 4).

← Referencia de generate.icons

Guía rápida

Lo mínimo para actualizar los iconos y llevarlos a tu proyecto. Primero conectas con Figma (una sola vez) y después le pides a Claude Code que haga el resto.

Parte 1 · Conectar con Figma una sola vez

  1. Abre una terminal en la carpeta generate.icons y ejecuta: 
    npm ci
  2. En Figma: tu avatar → Settings → Security → Generate new token. Marca solo File content: Read-only y copia el token (Figma lo muestra una sola vez).
  3. En generate.icons, haz una copia de .env.example y llámala .env. Ábrela y pega tu token: 
    FIGMA_TOKEN=figd_tu_token_aqui
  4. Comprueba que funciona: 
    npm run pull -- incontrol-icons --dry-run
    Si ves la lista de categorías e iconos, ya estás conectado.
El archivo .env no se sube al repositorio: tu token se queda solo en tu PC.

Parte 2 · Usar las skills en Claude Code

Abre Claude Code en la carpeta generate.icons y escribe el comando. Claude te hace las preguntas que falten.

Actualizar los iconos desde Figma

  1. Escribe /generar-fuente.
  2. Responde: fuente existente → incontrol-icons.
  3. Claude descarga los iconos y genera la fuente. Revisa el resultado abriendo en el navegador fonts/incontrol-icons/dist/incontrol-icons.html.

Llevar los iconos a tu proyecto

  1. Escribe /exportar-fuente.
  2. Responde el nombre de la carpeta (por defecto incontrol-icons) y la ruta de tu proyecto, por ejemplo C:/projects/mi-app/src/assets/fonts.
  3. Si ya había una copia, confirma que se sobrescriba. Listo: tu proyecto ya tiene los iconos nuevos.
También puedes pedirlo con tus palabras, por ejemplo: “actualiza los iconos desde Figma y llévalos a C:/projects/mi-app/src/assets/fonts”.

¿Algo falla o necesitas más detalle? Mira las guías completas: Conectar con Figma, Generar fuente y Exportar fuente.

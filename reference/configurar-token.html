Conectar con Figma (token)

Cómo crear y configurar el token personal de Figma que usa npm run pull para extraer los iconos de cada fuente directamente desde su archivo de Figma.

1. Para qué sirve

npm run pull lee el nodo de Figma registrado en cada fuente y descarga sus iconos como SVG usando la API REST de Figma. La API pide identificarse con un token personal (personal access token) de tu cuenta de Figma. 

Figma (nodo de iconos)
      │  npm run pull  ← FIGMA_TOKEN
      ▼
generate-fonts/fonts/<fuente>/source/   →   npm run build   →   dist/ + icons.json

Con el token, extraer cientos de iconos cuesta unas 3 peticiones (1 para la estructura y 1 por cada 100 iconos). Sin token, la alternativa es el MCP de Figma desde Claude, que hace una llamada por icono y choca con el límite de llamadas del plan.

2. Antes de empezar

  • Una cuenta de Figma que pueda abrir los archivos de Figma de las fuentes.
  • Node.js 22 o superior y las dependencias instaladas en generate-fonts/: npm ci.
  • Cada fuente con su URL de Figma registrada en figma de su fonts/<fuente>/icons.config.mjs (lo hace npm run new o /generar-fuente).

3. Crear el token

  1. Abre Figma (web o escritorio) con tu cuenta.
  2. Abre el menú de tu cuenta (tu avatar o nombre) y entra en Settings.
  3. Ve a la pestaña Security y busca la sección Personal access tokens.
  4. Pulsa Generate new token.
  5. Ponle un nombre que diga para qué y dónde se usa, por ejemplo generate-fonts – PC de Christian.
  6. Elige la caducidad (Figma la pide; anota la fecha para renovarlo a tiempo).
  7. En los permisos (scopes), marca solo File content: Read-only. No hace falta ningún otro.
  8. Pulsa Generate token y cópialo en ese momento: Figma lo muestra una sola vez. Si lo pierdes, genera otro.
Los nombres exactos de los menús pueden variar un poco según la versión de Figma. Lo importante: token personal, con permiso de solo lectura del contenido de archivos.

4. Guardarlo en .env

El token se guarda en generate-fonts/.env. Ese archivo está en el .gitignore: no se sube nunca al repositorio. Hay una plantilla, .env.example.

PowerShell

cd generate-fonts
Copy-Item .env.example .env
notepad .env

Git Bash / macOS / Linux

cd generate-fonts
cp .env.example .env
code .env      # o el editor que uses

Deja la línea así, con tu token y sin comillas ni espacios:

FIGMA_TOKEN=figd_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Comprueba que git lo ignora (debe imprimir la regla de .gitignore):

git check-ignore -v .env

También vale definir la variable de entorno FIGMA_TOKEN en vez del archivo (por ejemplo en un servidor de CI, como secret). Si existe, tiene prioridad sobre .env.

5. Probar la conexión

Desde generate-fonts/, una simulación que solo lee de Figma y no escribe nada:

npm run pull -- incontrol-icons --dry-run

Si el token funciona, verás el resumen de lo que hay en Figma:

[pull-figma] incontrol-icons: 187 icons from Figma (32 categories) [dry run]
  Navigation: 14
  Actions: 10
  Business and finance: 19
  …
  renamed (4): "icon-portafolio analysis" -> icon-portafolio-analysis, …
  skipped instances (2): icon-profitability-summary, icon-profitability-reports_02
[pull-figma] 1 Figma API request(s).

Si sale un error, busca el mensaje en Mensajes de error.

6. Un token, varias fuentes

El token es de tu cuenta, no de un archivo. No hay que configurar nada en cada Figma: uno solo sirve para todas las fuentes, y cada fuente extrae de su propio Figma.

FuenteDe dónde extrae (figma en su icons.config.mjs)Token
incontrol-iconsArchivo de Figma A, nodo de sus iconosEl mismo FIGMA_TOKEN
otros-iconsArchivo de Figma B, nodo de sus iconos
 
npm run pull -- incontrol-icons   # lee el Figma de incontrol-icons
npm run pull -- otros-icons       # lee el Figma de otros-icons

Solo hace falta que tu cuenta pueda abrir esos archivos. Si una fuente falla con 403/404 y las demás no, lo normal es que tu cuenta no tenga acceso a su archivo: pide acceso al dueño del Figma.

7. Generar la fuente

Resumen para fuentes de Figma; la guía completa (también para fuentes locales, sin token) está en Generar fuente.

  1. Simular y revisar el resumen: npm run pull -- <fuente> --dry-run.
  2. Extraer (reemplaza source/ con lo que hay en Figma): npm run pull -- <fuente>.
  3. Generar dist/ e icons.json: npm run build -- <fuente>.
  4. Llevarla al proyecto: Exportar fuente.
  • Duplicados: si dos capas de Figma dan el mismo nombre de icono, pull no escribe nada y las lista; renombra una en Figma.
  • Eliminados: un icono que ya no está en Figma no se genera; su SVG se guarda en fonts/<fuente>/trash/ con su código Unicode reservado. Si vuelve a Figma, recupera su código.

Con Claude Code, /generar-fuente hace los tres primeros pasos: pregunta la fuente (o crea una nueva con su URL de Figma), ejecuta la simulación, te muestra el resumen y, con tu confirmación, extrae y genera.

8. Seguridad

  • No subas el token a git, no lo pegues en chats (tampoco a Claude) ni en tickets o capturas.
  • Usa solo el permiso File content: Read-only: el script nunca escribe en Figma.
  • Un token por persona y equipo; el nombre del token ayuda a saber cuál revocar.
  • Si se filtra, revócalo en Figma (Settings → Security → Personal access tokens) y genera otro.
  • El script nunca muestra el token en la consola.

9. Caducidad y renovación

Cuando el token caduca, npm run pull responde con un 403 en todas las fuentes. Para renovarlo:

  1. Genera un token nuevo (paso 3).
  2. Reemplaza el valor de FIGMA_TOKEN en generate-fonts/.env.
  3. Revoca el anterior en Figma si aún aparece.
  4. Prueba con npm run pull -- <fuente> --dry-run.

10. Mensajes de error

MensajeCausaSolución
Missing FIGMA_TOKEN… No hay .env o la línea está vacía, y no existe la variable de entorno. Sigue Crear el token y Guardarlo en .env.
Figma refused the token (403) … Invalid token Token mal copiado, revocado o caducado. Revisa la línea de .env (sin comillas ni espacios) o renuévalo.
Figma refused the token (403) Solo en una fuente: tu cuenta no tiene acceso a ese archivo de Figma. Pide acceso al archivo al dueño del Figma.
Figma file or node not found (404) La URL de figma apunta a un archivo o nodo que no existe (borrado, movido o mal copiado). En Figma, selecciona el frame de iconos, Copy link to selection y actualiza figma en su icons.config.mjs.
… has no Figma URL La fuente no tiene figma registrado. Regístralo en su icons.config.mjs o con /generar-fuente.
Figma rate limit (429), retry after … Demasiadas peticiones seguidas a la API de Figma. El script ya reintenta solo con esperas cortas; si pide esperar más, espera ese tiempo y repite.
No icons in "…" whose name starts with "…" El filtro figmaFilter no coincide con ninguna capa, o el nodo no es el de los iconos. Revisa figmaFilter y la URL de figma.
Invalid icons: … is duplicated Dos capas de Figma dan el mismo nombre de icono. Renombra una de ellas en Figma y vuelve a ejecutar.

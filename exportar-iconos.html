Exportar iconos

1. Por qué exportar

generate-fonts/ solo genera fuentes: tiene sus propias dependencias y no forma parte de ninguna aplicación. Ningún proyecto debe referenciar archivos dentro de generate-fonts/.

En su lugar, la fuente generada se copia a una carpeta del proyecto, y el proyecto usa esa copia. Así el proyecto no depende de dónde esté generate-fonts/ ni de sus dependencias. 

generate-fonts/fonts/incontrol-icons/dist/  +  icons.json
            │
            │  npm run export
            ▼
<proyecto>/src/assets/fonts/incontrol-icons/   ← el proyecto referencia esta copia

2. Requisitos

  • Node.js 22 o superior.
  • Dependencias instaladas en generate-fonts/ (solo la primera vez): npm ci.
  • La fuente generada: SVG en fonts/<fuente>/source/ (en carpetas de categoría o directos) y npm run build (todas) o npm run build -- <fuente> ejecutado. La exportación no genera; copia lo que ya hay en dist/. 
cd generate-fonts
npm ci          # solo la primera vez
npm run build   # cada vez que cambian los SVG

3. Comando

Desde la carpeta generate-fonts/:

npm run export -- <fuente> <ruta> [--folder <carpeta>] [--force]

El -- después de export es obligatorio: separa los argumentos de npm de los del script.

ArgumentoObligatorioQué es
<fuente> Sí Carpeta de la fuente dentro de generate-fonts/fonts/: incontrol-icons, incontrol-system, …
<ruta> Sí Carpeta donde se crea la carpeta de iconos. Mejor absoluta y entre comillas. Si es relativa, se resuelve desde la carpeta donde ejecutas npm.
--folder <carpeta> No Nombre de la carpeta a crear dentro de <ruta>. Por defecto, el nombre de la fuente (incontrol-icons). Solo letras, números, ., _ y -.
--force No Sobrescribe una copia anterior. Sin él, si ya existe una copia, no se escribe nada.

4. Ejemplos

Primera exportación

npm run export -- incontrol-icons "C:/projects/mi-app/src/assets/fonts"

Crea C:/projects/mi-app/src/assets/fonts/incontrol-icons/ con los 9 archivos.

Con otro nombre de carpeta

npm run export -- incontrol-icons "C:/projects/mi-app/src/assets" --folder icons

Crea C:/projects/mi-app/src/assets/icons/. Los archivos dentro siguen llamándose incontrol-icons.*; solo cambia el nombre de la carpeta.

Actualizar una copia existente

npm run export -- incontrol-icons "C:/projects/mi-app/src/assets/fonts" --force

Sobrescribe los 9 archivos. Cualquier otro archivo que hayas puesto en esa carpeta se conserva.

Desde otra carpeta, con ruta relativa

# ejecutado desde C:/projects/mi-app
npm --prefix C:/christian/projects/custom-components/generate-fonts run export -- incontrol-icons src/assets/fonts

La ruta relativa se resuelve desde C:/projects/mi-app, que es donde se ejecutó npm.

5. Qué se copia

<ruta>/<carpeta>/
├── incontrol-icons.css     # @font-face + una clase por icono (.icon-search)
├── incontrol-icons.woff2   # fuente (formato principal)
├── incontrol-icons.woff
├── incontrol-icons.ttf
├── incontrol-icons.eot
├── incontrol-icons.svg
├── incontrol-icons.html    # vista previa de todos los iconos (ábrela en el navegador)
├── incontrol-icons.json    # nombre → código Unicode: "icon-search": 61698
└── icons.json              # iconos por categoría y/o sin categoría

icons.json sigue la organización de source/: los iconos en carpetas de categoría van en categories, y los SVG puestos directamente en source/ (sin categoría) van en icons.

source/ tieneicons.json tiene
Solo carpetas de categoríacategories
Solo SVG directosicons
Amboscategories e icons
 
{
  "name": "incontrol-icons",
  "categories": [
    {
      "category": "Navigation",
      "slug": "navigation",
      "icons": [
        { "name": "icon-nav-left", "code": 61697, "unicode": "f101" }
      ]
    }
  ],
  "icons": [
    { "name": "icon-logo", "code": 61698, "unicode": "f102" }
  ]
}

Cada clave aparece solo si tiene iconos: el código que lea el JSON debe tratar categories e icons como opcionales.

6. Reglas y validaciones

Antes de copiar, el script comprueba lo siguiente. Si algo falla, no escribe nada.

  • La fuente existe: hay fonts/<fuente>/icons.config.mjs.
  • La fuente está generada: existen los 8 archivos de dist/ y icons.json.
  • El destino está fuera de generate-fonts/: la copia es para un proyecto, no para el generador.
  • No hay copia anterior, o se pasó --force.

Además:

  • Si la ruta no existe, se crea.
  • Solo se escriben esos 9 archivos. Nunca se borra nada: cualquier otro archivo en la carpeta destino queda intacto.

7. Con Claude Code: /exportar-iconos

El skill está en generate-fonts/.claude/skills/exportar-iconos/. Puedes invocarlo con /exportar-iconos o pedirlo en lenguaje natural (“exporta los iconos a C:/projects/mi-app/src/assets/fonts”).

  1. Te pregunta, en un solo mensaje, el nombre de la carpeta (por defecto incontrol-icons) y la ruta.
  2. Si la fuente no está generada, te ofrece ejecutar npm run build -- <fuente>.
  3. Si ya hay una copia en el destino, te muestra qué archivos hay y pide confirmación antes de sobrescribirlos.
  4. Ejecuta el comando con la ruta absoluta y te indica la carpeta resultante.
El skill no modifica angular.json ni otros archivos del proyecto destino salvo que lo pidas expresamente. Al estar dentro de generate-fonts/, puede que solo aparezca en una sesión nueva de Claude Code.

8. Usarlo en el proyecto

El proyecto referencia la copia. En Angular, añade el CSS a styles en angular.json:

"styles": [
  "src/styles.scss",
  "src/assets/fonts/incontrol-icons/incontrol-icons.css"
]

Angular copia los archivos de fuente automáticamente, porque el CSS los referencia con rutas relativas. En cualquier plantilla: 

<i class="icon-search"></i>
<span class="icon-nav-left" aria-hidden="true"></span>

El tamaño y el color se heredan del texto:

.toolbar__icon {
  font-size: 24px;
  color: currentColor;
}

Fuera de Angular basta con <link rel="stylesheet" href="ruta/incontrol-icons/incontrol-icons.css">.

9. Actualizar iconos

  1. En Figma, en el nodo registrado en figma de icons.config.mjs: Outline stroke + Flatten a los iconos nuevos o cambiados.
  2. Regenerar con /generar-fuente (lee Figma, actualiza source/ y ejecuta el build). Sin Claude: guardar los SVG en generate-fonts/fonts/incontrol-icons/source/ (en su carpeta de categoría o directos) y npm run build -- incontrol-icons.
  3. Revisar dist/incontrol-icons.html.
  4. Volver a exportar con --force (o con /exportar-iconos, confirmando la sobrescritura).

Los iconos existentes conservan su código Unicode al añadir otros nuevos, así que las clases ya usadas en el proyecto siguen funcionando.
